# README Theme Guide — Raj Rathod

The profile README uses a clean **white / blue / light-green** palette with dark navy panels for GitHub cards. It avoids generic neon/cyber styling and keeps the focus on AI/ML work.

## Current theme: Blue + Mint

| Role | Color | Hex |
|---|---|---|
| Main blue | Primary accent | `#2563EB` |
| Soft blue | Animated accents | `#60A5FA` |
| Light green | Secondary accent | `#86EFAC` |
| White | Text / highlights | `#F8FAFC` |
| Navy | Card background | `#0B1220` |

### Theme usage
- Typing animation: soft blue
- Links and badges: blue
- Supporting highlights: light green
- Stats cards: navy with white, blue and mint details
- Layout: minimal, project-first and compact

## Optional accent variants

### Blue + Mint (default)
- `#2563EB` blue
- `#60A5FA` soft blue
- `#86EFAC` mint

### Blue + White
Use `#2563EB`, `#FFFFFF`, `#E2E8F0` for a cleaner, lighter accent balance.

### Forest + Sky
Use `#16A34A`, `#86EFAC`, `#60A5FA` for a greener accent balance.

## Animation and external assets

GitHub README markdown does not support arbitrary CSS hover effects or JavaScript. Use supported animated SVGs, GIFs, badges and typing SVGs instead.

The contribution snake is generated by `.github/workflows/snake.yml` and published to the `output` branch. If the snake image is missing, check the Actions workflow run and repository Actions permissions.

## Files
- `README.md`: profile content
- `.github/workflows/snake.yml`: scheduled/manual snake generator
- `THEMES.md`: theme palette and maintenance guide
- `preview.html`: local preview wrapper for README markdown (requires network access to load README and the Markdown renderer)


## Stats-card contrast maintenance

The streak-card URL explicitly sets `currStreakNum` and `sideNums` to light text (`#F8FAFC`) so numerical values remain readable against the navy background. The card also sets `stroke` and label colors. When editing the streak URL, preserve these contrast parameters.
